## Recorded limits

- `varve.capture.node`
  - Captures document pixels rendered by the export pipeline, not a screenshot of the application window or a native GPU surface.
  - One node per call, PNG only, longest edge at most 2048 px and at most 2 MiB encoded.
  - Real pixel rendering is exercised in a browser run; jsdom unit tests inject the renderer.
- `varve.document.save`
  - Not available under `varve exec`/`varve batch`, which attach no external handler; those write results with --in-place/--out instead.
  - A live session saves only where the person already chose; a never-saved or download-only document, a browser file handle, or any caller-chosen path is refused and nothing is written.
  - A live save reports the revision written and the destination; it does not report byte size or hash, because the editor persistence layer owns encoding.
- `varve.history.rollback`
  - Compensating and attributed: it reverts one named transaction and refuses on conflict. It never pops the last N edits.
  - Undo/redo as a user presses them are a different mechanism (the editor's snapshot stack) and are not this command.
- `varve.node.create`
  - Creates rect, ellipse, frame and text only. group, table, adjustment, path and raster nodes are read-only through the catalog.
  - Cannot reproduce a drag-to-create gesture's intermediate samples; only the committed result.
- `varve.node.find`
  - Reports ambiguity; it never coerces a name into an id.
- `varve.node.group`
  - Members must already share a parent; use varve.node.reparent first. The editor's Group action silently does nothing for mixed parents, the command refuses and says why.
- `varve.node.move`
  - Align and distribute are not the same operation and are not covered by `by`.
- `varve.node.reorder`
  - Reports a no-op at the boundary rather than clamping.
- `varve.node.resize`
  - Refuses kinds without a direct size instead of guessing one.
- `varve.node.set`
  - Typed properties only (name, visible, locked, opacity, rotation, blendMode, fill, text, fontSize). No arbitrary property path.
  - Writes a static opacity; the editor's own setter also feeds motion auto-keyframing while a timeline plays.
  - Nodes with stacked fills reject a single `fill` rather than silently changing nothing.
- `varve.node.ungroup`
  - A live boolean group is refused: the editor expands it into a path, which is a different operation that has no command yet.

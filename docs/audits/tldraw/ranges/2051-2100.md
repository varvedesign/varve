# tldraw issue review: positions 2051–2100

Reviewed 50 issue bodies (#7781–#7959) and all 131 retrievable comments.
Individual dispositions are recorded in `../assessments/range-2051-2100.jsonl`.

## Findings

- Confirmed upstream fixes/deliveries include stylus recovery after zoom
  (#7787, reported fixed in 5.1.1), paste parenting (#7827, #8057), centralized
  shape culling (#7831, #7841), canvas overlay utilities (#7869, released in
  5.0), and InFrontOfTheCanvas z-ordering (#7864, #7865). The custom-crop
  report (#7927) points to a closed PR but has no comments to verify its result.
- Reports with a specific behavioral or rendering concern but no confirmed
  resolution include zoom-to-selection outside select mode (#7810), clipped
  arrow endpoints (#7824), shift-click stroke corners (#7867), dynamic-size
  pattern fill (#7862, possibly duplicating #7545), paste handler differences
  (#7883), text-edit viewport scrolling (#7797), link editors after remote
  deletion (#8049), and batch resize cost (#7943). These are not treated as
  Varve defects without local reproduction.
- Several reports are upstream dotcom/deployment concerns: share permissions
  (#7781), ErrorPage localization (#7799), Durable Object migration and
  Cloudflare deployment (#7804, #7806), fairies removal (#7808), invite routing
  (#8035), Sentry setup (#7882), old asset-worker retirement (#7901), login
  with 1Password (#7956), and deployment-triggered license handling (#7805,
  later identified as a red herring).
- SDK and developer requests cover custom shape behavior, toolbar groups,
  multi-runtime sync clients, awaitable sync acknowledgement, overlay APIs,
  icon packs, equations, test tooling, and templates (#7783, #7868, #7874,
  #7857, #7892–#7894, #7950, #7944–#7954). Resolved, declined, duplicate, and
  stale-closed requests are distinguished in the ledger.
- The SVG sanitization report (#7876) flags potentially executable imported
  content and remains a security follow-up; this corpus evidence was not
  independently reproduced against Varve. Infrastructure and example requests
  (#7851–#7853, #7908, #7960–#7967) remain specific to the upstream repository.

## Validation

All 50 issue bodies and all 131 comments available in the frozen cache were
assessed and imported into the ledger. `pnpm audit:docs` validates the report,
assessment index, ledger links, and documentation index. No Varve code change
was made based only on this upstream batch.

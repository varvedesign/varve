Reviewed 50 issue bodies (#8162–#8342) and all 92 comments available in the
frozen cache. The issue inventory declares 95 comments for this range; three

## Findings

- Confirmed upstream changes include the zero-length arc-arrow render failure
  (#8190, fixed by #8350), the `useTransform` effect dependency correction
  (#8234), wheel zoom without Ctrl through the existing Mouse input setting
  (#8246, added by #6755), and paste-during-drag handling (#8305, PR #8976).
  The skip-to-canvas overlap flicker (#8328) was partly addressed, while the
  temporary Back to content button during camera movement was considered
  expected behavior.
- Interaction and rendering reports without verified fixes include deletion of
  a bent arrow with adjacent bound shapes (#8174), arrow drift across undo/redo
  (#8203), hidden arrows after changing a bound shape type (#8207, not
  reproduced by a maintainer), and context-menu dismissal on consecutive
  right-clicks (#8251). The coarse-pointer long-press report (#8277) identifies
  missing long-press handlers and differing creation timing across tools.
- Editor API or design proposals include viewport-only select-all (#8170),
  JSON copy-as (#8205), the separate undo/redo change source (#8233), migrating
  overlays to canvas rendering (#8314), duplicate-binding warnings (#8324),
  and group-center arrow binding (#8342). The existing Ctrl-free wheel setting
  (#8246) was already available upstream.
- Dotcom, deployment, and repository reports include production licensing
  guidance (#8248), release-pipeline issues later reported resolved (#8218),
  and the proposal to move tests out of the public repository (#8082). The
  memory retention investigation (#8440) is outside this reviewed position
  range and remains a later research lead.
- The repository-governance discussion (#8082) includes community debate and a
  maintainer clarification that the proposal was partly a joke; no change to
  Varve's validation or test policy follows from it. Three undeclared missing
  comments are documented as retrieval gaps, not assumed discussion outcomes.

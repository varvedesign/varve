# tldraw issue review: positions 2201–2250

Reviewed 50 issue bodies (#8343–#8528) and all 80 retrievable comments.
Individual dispositions are recorded in `../assessments/range-2201-2250.jsonl`.

## Findings

- Confirmed upstream outcomes include invalidated PostgreSQL replication-slot
  recovery (#8487, fixed by #8510), and the combined image/display incidents
  tracked by #8428 and its duplicates (#8411, #8426), though a user still
  reported SVG omissions and delayed availability. The timing-comparison report
  (#8366) was explicitly closed as low practical risk for its health endpoint.
- High-impact local follow-up leads include camera state stuck at `moving`
  after viewport deep links (#8386), module-level retention of editor/store
  objects after unmount (#8430, tracked more broadly in #8440), and recurring
  image-edge artifacts during pan, zoom, and resize (#8482). These were not
  reproduced in Varve during this batch and require separate source checks.
- Other unresolved interaction/render reports include text paste positioning
  (#8343), high-zoom dynamic-size shadows/carets (#8377–#8379), minimap click
  offsets (#8383, closed as not reproducible), pinch-selection changes (#8397),
  right-click selection behavior (#8433), Mermaid paste classification
  (#8481), quick-zoom offsets in embedded layouts (#8500), offscreen-frame
  paste placement (#8516), and Safari opacity-slider dragging (#8517).
- The source-level clustering of editor memory leaks (#8440) reports retention
  through window globals and scheduled clients, with a specifically described
  iOS WebView impact. This is separate from the earlier hard-reset global
  report (#8430) and merits lifecycle ownership analysis before any analogous
  Varve change.
- SDK requests include custom cast shadows, styled text defaults, overlap-based
  layout clusters, scale adjustment, custom themes, undo/redo change sources,
  nested-frame labels, polygon text layout, arrow obstacle avoidance, and
  auto-alignment (#8359, #8431–#8432, #8454–#8455, #8467, #8473, #8477,
  #8507, #8525). Dotcom content export/theme and deployment issues are kept
  separate from Varve's marketing site and local editor scope.
- Repository proposals and promotions (#8375, #8496, #8514) do not describe
  Varve product behavior. Closed/stale issue status is not treated as proof
  that a proposed behavior was delivered.

## Validation

All 50 issue bodies and all 80 retrievable comments were assessed and imported
into the ledger. `pnpm audit:docs` validates the range report, assessment index,
ledger, and documentation links. No Varve code change was made based only on
this upstream evidence.

# tldraw issue review: positions 1951–2000

Reviewed 50 issues (#7576–#7662) and all 145 retrievable comments. Individual
assessments are recorded in `../assessments/range-1951-2000.jsonl`.

## Findings

- Confirmed upstream changes include custom themes (#7587), laser-pointer
  behavior under active discussion (#7579, not yet confirmed landed), the
  TldrawOptions camera/deep-link/text migrations (#7603, #7605, #7606),
  zoom-to-fit padding (#7599, alongside #7515), geometry distance semantics
  (#7609), ESLint caching (#7617), bullet-list editing (#7641), indicator
  scaling (#7646), and style sampling (#7659).
- Several specific interaction reports remain unresolved or lack fix evidence:
  nested-group flips (#7582), selected-shape “back to content” visibility
  (#7644), tiny-zoom dotted strokes (#7648), and toolbar drags while pen mode
  is enabled (#7662). They were not reproduced in Varve in this review.
- The Android rapid-stylus report (#7647) was investigated upstream and closed
  after maintainers could no longer reproduce it. It remains distinct from
  the earlier low-pressure touch report (#7203).
- #7577 documents a multiline highlight seam with possible CSS/line-height
  causes; no fix was recorded. #7637 similarly proposes a different random
  offset distribution for hand-drawn geometry without a confirmed patch.
  Varve output has not been visually compared for either case.
- Build, lint, deployment, and performance-test requests (#7586, #7613–#7634)
  concern tldraw's own repository infrastructure. The discussion distinguishes
  measured setup trade-offs from completed actions and does not imply Varve
  changes.
- The logged-out Fairy UI and max-file preload reports (#7588, #7624, #7645,
  #7652, #7653) are specific to tldraw.com authentication and sync flows.
  The tldraw.com examples and proposed migration strategies are not applicable
  to Varve's local-first application.

## Validation

All 50 issue bodies and 145 retrievable comments were assessed and atomically
imported into the ledger. `pnpm audit:docs` is run for this report, index, and
ledger. This documentation-only batch selects no application tests. No Varve
implementation change was justified from the evidence in this range.

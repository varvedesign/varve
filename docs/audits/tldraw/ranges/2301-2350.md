# tldraw issue review: positions 2301–2350

Reviewed 50 issue bodies (#8745–#8878) and all 79 retrievable comments.
Individual dispositions are recorded in `../assessments/range-2301-2350.jsonl`.

## Findings

- Confirmed upstream changes include right-click context menus in all tools
  (#8828, fixed by #8948), a locked-shape selection affordance fix (#8839,
  reported solved), dark-mode pattern-fill export (#8854, fixed in 5.1.0),
  group rollout to workspaces (#8859), and marketing navigation from the
  dotcom logo to tldraw.dev (#8871, #8979). Closing state alone is not treated
  as confirmation of delivery.
- Accessibility and pointer interaction leads include mobile screen readers
  not announcing a canvas with `role="application"` (#8849), visible-state
  feedback on selected-shape hover priority (#8822), arrow/body target design
  (#8847), and overlay input routing over interactive shapes (#8873). The
  mobile accessibility report received maintainer acknowledgement but no
  resolution in the retrieved comment.
- Other editor reports include selection behavior around shape handles
  (#8840), group-child z-order on deletion (#8857), locked group transforms
  (#8858, with only resize/flip targeted by #9005), and page-menu sizing
  (#8862). This range also contains proposals for custom connection ports,
  color derivation, palette expansion, crop targeting, style shortcuts, and
  post-create tool customization (#8847, #8855, #8809, #8817, #8820, #9048).
- Tooltip requests (#8816, #8868) led to a design/accessibility objection to
  disabling them globally. The issue about Copy/Cut intercepting selected page
  text (#8870) was clarified as current intended clipboard behavior, with the
  editor exposing a focus/blur example for embedded hosts.
- Dotcom-specific reports concern workspace settings, auth, deployment
  pipelines, expiring invites, Maps configuration, issue templates, and
  presentation links. They do not imply changes to Varve’s local-first
  marketing site. The proposed tldraw.dev logo link (#8871) is an upstream
  cross-site marketing change, already confirmed in #8979.
- Package and example requests (#8759, #8795, #8835, #8856) and the migration
  guide request were assessed independently from product behavior. The empty
  #8856 example-request record has no body or comments to characterize.

# tldraw issue review: positions 2101–2150

Reviewed 50 issue bodies (#7960–#8159) and all 84 retrievable comments.
Individual dispositions are recorded in `../assessments/range-2101-2150.jsonl`.

## Findings

- Confirmed upstream fixes include the dynamic-size dashed-shape rendering
  correction (#7999, PR #8040), Firefox touchscreen pinch zoom (#8142), and
  corrected lock/unlock documentation (#8156, #8460). The multi-shape view
  source issue (#8046) was explained as a path mismatch left by example
  reorganization; discussion says release fixes were expected but did not
  record a final verified URL.
- Concrete editor/API reports without a confirmed resolution include Meta key
  reactive state (#7981), missing `currentPageId` in session snapshots (#7993),
  toolbar-created shapes ignoring dynamic sizing (#7998), callbacks skipped by
  `createShape` with `parentId` (#8078), arrow endpoints at exact shape edges
  (#8125), autosize action visibility (#8144), and image alt text (#8152).
  These remain upstream evidence only, without Varve-specific reproduction.
- The pen-after-zoom report (#7787) was reported fixed in 5.1.1 after a series
  of stylus/pointer changes. A separate group of reports concerns contenteditable
  or rich-text behavior: viewport scrolling (#7797), link editing after remote
  deletion (#8049), paste formatting (#8209), rich-text insertion from a copied
  shape (#8187), and highlighted text outline in dark mode (#8189).
- Dotcom/hosted-service incidents include shared-view permissions (#7781),
  invite routing (#8035), failing image upload with a reported CORS path
  (#8159), Cloudflare sync licensing (#8131), and Debug SVG blocked by
  production CSP (#8141). The latter explicitly retains the hosted restriction
  for security while permitting a development fix.
- SDK and documentation proposals include framework integration guides,
  example-app search/source UX, shape vertex insertion, extensible geo types,
  an Editor resize helper, and viewport-only select-all
  (#7960–#7967, #7983, #8064, #8076, #8116, #8170). The
  opinionated hosted product explicitly declines inline text colors (#8118).
- No-login verification (#8115), upstream deployment/release maintenance
  (#8099, #8104, #8106, #8107), and the proposed test-repository move (#8082)
  are recorded as context rather than Varve engineering requirements.

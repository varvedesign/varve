## Batch conclusion

No Varve defect was reproduced and no implementation is justified by this slice. Follow-up leads include locked-child preservation during ungroup (#2045), misleading eraser feedback on locked objects (#2058), Android image cropping and text resizing (#2080, #2131), and print/PDF frame composition (#2147). The thread also surfaces larger product/API opportunities around bounded export sizing (#2137), multiple connector labels (#2141), and screen-pinned reference objects (#2151); each needs explicit Varve behavior and scope before implementation. Offline drawing (#2115), PDF output (#1988 from the prior range), and configurable token overrides are already present. VS Code/JetBrains extension reports are outside the current product surfaces.

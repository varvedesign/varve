## Batch assessment

The clearest Varve follow-up candidates in this range are large-document stylus performance/fidelity (#1246–#1247), measured-layout workflows (#1243–#1244), large-image progress and decode feedback (#1261), browser persistence failure signaling (#1262), and cross-page navigation (#1260). These remain investigation candidates: no Varve reproduction was performed, so this report does not claim a defect or justify immediate code changes. The strongest existing matches are copy-as-SVG, save/termination guards, contextual learning, and file import/export routes, all identified through source inspection rather than a full workflow run.

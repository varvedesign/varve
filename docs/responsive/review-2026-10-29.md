## Round 2 — task 01a safe-area foundation (0957d2db6, fixed in 95f2b82a0)

Independent reviewer: cdp-scout (separate agent, read-only) reviewed the first
01a code commit and returned one blocker, two should-fix findings and four nits.

**Blocker (fixed).** The first pass added a later @media (min-width: 900px)
block in layoutPresentation.css whose selectors were identical to the existing
inspector-aware tablet launcher rules, so it won the cascade and dropped
var(--inspector-width): non-mirrored library and mirrored layers launchers moved

the generic >=900 FAB block in editor.css was deleted as dead. The new tablet
harness pass asserts the 280px inspector floor for standard and mirrored
presentations, so a regression of this class now fails CI.

**Should-fix (fixed).** (1) The task claimed exit-focus and drawer-anchor
coverage that did not exist; the harness now toggles distraction-free mode
through the real Ctrl+Shift+'>' shortcut and measures the exit control, and the
drawer anchor is asserted with a with-insets-vs-CDP-cleared differential (so a
forgotten inset fails even when the static estimate is already approximate).
(2) No >=900 tablet or env()=0 control existed; both were added, plus explicit
presence checks for the toast container and launchers.

**Nits (addressed).** The shell comment claimed contextual help was inset but it
was not: contextual-help panel, app skip link and safe-mode indicator now carry
the insets. buildEditorChecks/editorProbe were split into page-probes.mjs +
probes.mjs + per-device capture modules so every function is under the 50-line
ceiling and every .mjs stays under the 400-line cap.

**Nits (recorded, not actioned).** The spotlight tooltip and floating-layer
portals are still positioned by their own JS next to their target; they are
transient overlays that can land under a landscape notch. They are out of the
task 01a chrome scope and are carried as a follow-up in audit.md.

**Validation after the fix.** pnpm validate:safe-area 124/124 PASS (phones,
tablet >=900 standard+mirrored, exit-focus, env()=0 desktop baseline, site

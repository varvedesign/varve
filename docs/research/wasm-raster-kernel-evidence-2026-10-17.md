# WASM raster kernel: user reports and platform evidence

**Reviewed:** 2026-10-17 (Vancouver) · **Scope:** targeted review of the 19
issue leads named by the implementation brief, plus selected Squoosh reports
and primary platform documentation. This is not an exhaustive tracker audit;
the upstream apps were not reproduced. A closed issue is not treated as
shipped without linked merge/release evidence.

## Technical constraints verified for this work

- [WebAssembly.Memory.grow](https://developer.mozilla.org/en-US/docs/WebAssembly/Reference/JavaScript_interface/grow) can detach cached non-shared JS views. Any caller that retains views across a grow must refresh them.
- [Transferable worker buffers](https://developer.mozilla.org/en-US/docs/Web/API/Web_Workers_API/Using_web_workers#transferring_data_to_and_from_workers) move ownership and detach the sender's buffer; an effect worker must not transfer the document's only copy.
- [wasm-feature-detect](https://github.com/GoogleChromeLabs/wasm-feature-detect) treats SIMD and threads as independent capabilities. Shared-memory threads additionally need cross-origin isolation; this project’s public GitHub Pages host cannot provide those headers.
- [Canvas premultiplied-alpha semantics](https://html.spec.whatwg.org/multipage/canvas.html#premultiplied-alpha-and-the-2d-rendering-context) can change low-alpha/hidden-RGB values at canvas conversion boundaries. Pixel tests should cover transparent and partially transparent edges.
- Rust's [`imageops::resize`](https://docs.rs/image/0.25.10/image/imageops/fn.resize.html) documents alpha/scene-linear assumptions; this is evidence to test the existing path, not a requirement to replace it.
- [Tauri's CSP guide](https://v2.tauri.app/security/csp/) and [webview-version matrix](https://v2.tauri.app/reference/webview-versions/) establish that desktop WebKitGTK/WKWebView/WebView2 qualification differs from Chromium browser tests. A browser pass does not certify packaged desktop.

## Search scope and limits

The 19 seeded issue threads were checked for body, visible comments/activity, linked PR or commit status where available, and evidence type. Related reports were deduplicated; Artcraft #2379 concerns PhotoCraft and is not counted as a second independent WebP failure. The issue set is a targeted sample, not a search of every tracker record. The upstream applications and supplied issue media were not executed locally. Browser and pixel validation in Varve is required before a report is called reproduced.

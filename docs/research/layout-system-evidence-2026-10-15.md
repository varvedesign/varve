## Current Varve source audit

- `packages/layout/src/reflow.ts` is called by editor sizing and structural
  mutations; it writes resolved geometry into the existing scene.
- `packages/layout/src/computeFlexLayout.ts` uses version-2 hypothetical bases
  and line-local Fill for new wrapped layouts. Missing/version-1 styles keep
  their global Fill allocation and previous wrap membership. It redistributes
  around min/max bounds and maps independent row/column gaps to physical axes
  for the versioned path; 36 exact flex tests passed on 2026-10-21.
- `packages/layout/src/computeGridLayout.ts` now rejects unsupported track
  syntax and bounds repeat expansion, placement spans, children, and cell work.
  The detailed result reports typed failure reasons; the layout inspector shows
  a read-only explanation and confirms that existing child positions were kept.
  `layoutSemanticsVersion: 2` resolves intrinsic/span contributions before
  fractional tracks and repeats authored implicit tracks; absent/version 1
  retains legacy sizing. Stable track identities and editor mutations remain.
- `packages/scene/src/constraints.ts` preserves proportional `center` and adds
  `centerOffset`, which keeps the child center's offset from the parent center.
- `packages/layout/src/gridTrackMutations.ts` persists stable track identities,
  provides add/resize/reorder operations, and computes removal/rehome previews
  without mutating the source document. The inspector applies style and child
  placement changes through one `updateDoc` call.
- `packages/codegen/src/html-layout-css.ts` and `css.ts` preserve grid track definitions,
  independent gaps, track-ID anchors, and spans in CSS output.
- `crates/varve-layout/src/lib.rs` has no production callers and leaves grid
  templates as a stub; TypeScript remains the active layout solver.
